# Shrimp's Immersive Interfaces changelog


## Version 0.9.1

### New Features

- the regular and bundle tooltip have been replaced by custom ones, so as to bring the java pack's tooltips

### Feature Changes

- improved the contrast of the smelting timer with Déesse UI
- slightly changed the creative menu texture to better reflect where the scroll panel finishes
- re-added the category label to the creative menu

### Bug Fixes

- slight improvements to compatibility with other packs
- the hotbar overlay scales correctly with touch controls now
- touch screen has the correct selected recipe slot texture
- the size and offset of the creative menu scroll box on touch screen is correct
- the entirety of the scroll box now fades away correctly on touch screen
- fixed a bug which caused the search tab in the furnace recipe book not to appear
- the search bar in the furnace screen is now enabled only in the appropriate tab
- the recipe book now always renders behind the smoker or blast furnace door
- adjusted the offset of the arrow and of the bubbles in the brewing stand screen
- added missing pixels to the hotbar overlay with the xp bar
- the highlight slot correctly renders on top of the count label
- the slots still compare in the brewing stand screen with Déesse UI
