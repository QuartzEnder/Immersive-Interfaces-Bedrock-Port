This Github Repo contains preview builds of the Bedrock version of Shrimp's Immersive Interfaces so as to test them before official release. Here's how to do it:

- make sure you don't have any other version of Immersive Interfaces or else the game will reject importing it
- you can check that by going to 'settings' (main menu), then 'global resources' and lastly 'my packs'
- click on 'Code'
- click on 'Download zip'
- rename the file from a .zip file to a .mcpack file
- double click the .mcpack file (make sure Minecraft is already closed)
